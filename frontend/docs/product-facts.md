# TranslatePDFOnline 产品事实基线

> 最近核验：2026-10-27
>
> 用途：SEO、GEO、帮助文档、结构化数据和多语言内容发布前必须先对照本表。动态事实不得写成长期固定承诺。

## 1. 已由代码确认的事实

| 事实         | 当前结论                                                                                | 代码 / 政策来源                                          | 内容规则                                                                                              |
| ------------ | --------------------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 支持语言     | 英语、中文、西班牙语、法语、意大利语、希腊语、日语、韩语、德语、俄语，共 10 种          | `src/shared/lib/translate-langs.ts`                      | 只能使用这 10 种；不得再声明 Norwegian / 挪威语                                                       |
| 文件上传登录 | 上传和处理文件前需要登录                                                                | `UploadDropzone.tsx`；翻译、OCR、文档对比 API 的用户校验 | 可以写“无需安装”；不得写“无需账号/无需注册即可处理”                                                   |

| 处理位置     | 上传、预览、下载由浏览器界面操作；OCR、翻译、对比和文档重建通过后端服务执行             | OCR、翻译、对比 API 与任务 Worker                        | 不得写“所有处理都在浏览器完成”；应区分浏览器操作界面和后端计算                                        |
| 新用户积分   | 是否赠送、数量和有效期均由运行时配置决定                                                | `src/shared/models/credit.ts`                            | 只能写“当前配置启用时可能提供体验积分”，或引导用户查看账户/定价页；不得保证每个新用户都有固定免费积分 |
| 处理计费     | 使用当前运行时积分配置，翻译/OCR 成本由接口返回                                         | `translate/billing-config`、OCR/转换处理代码             | 不在静态 SEO 文案中写死每页积分或固定价格                                                             |
| 通用上传上限 | 翻译工作流客户端限制为 100 MB，且必须与服务端配置一致                                   | `UploadDropzone.tsx`                                     | 只在对应工作流中写 100 MB，不把它扩展到所有工具                                                       |
| 文档对比输入 | PDF、DOC、DOCX、WPS、PNG、JPG/JPEG、BMP、TIFF                                           | `api/translator/compare/route.ts`                        | 不得写“任意格式”                                                                                      |
| 文档对比大小 | 每份文件最多 50 MB                                                                      | `api/translator/compare/route.ts`                        | 明确是“每份文件”，不写无限大小                                                                        |
| 文档对比权限 | 登录用户只能访问自己的任务；支持主动删除历史任务                                        | compare API 的用户过滤与 DELETE 路由                     | 可以写账户隔离和可主动删除；不得宣称未经证实的企业认证                                                |
| 文件保留     | 文档记录和对象通常按约 7 天保留策略安排删除，受公开政策和法律例外约束                   | 上传完成路由、清理路由、Privacy Policy                   | 使用“通常约 7 天/按公开政策”；不得写“处理完成立即删除”                                                |
| 规范域名     | `https://translatepdfonline.com`                                                        | `src/config/seo-routes.ts`                               | 内链、canonical、sitemap、结构化数据统一使用 apex，不使用 `www`                                       |

## 2. 已确认不能继续使用的表述

- “支持 Norwegian / 挪威语”。
- “无需注册、无需账号即可上传或处理文件”。
- “每个新用户一定获得固定免费积分”。
- “任意文件格式”“无限文件大小”。
- “完美保留全部字体、表格、印章、手写和版式”。
- “SOC 2 compliant / enterprise certification”，除非有可公开核验的当前证书。
- “将审查时间降低 70%”“消除人工错误”“管理数百/数千合同”等无公开测试依据的结果承诺。
- 把文档差异比较工具描述为完整的 CLM、审批、续约或合规管理系统。

## 3. 场景化内容的事实边界

### PDF 翻译 / OCR

- 可描述：文字型和扫描型 PDF；扫描件先 OCR，再翻译；支持 10 种语言；可在工作台校对识别结果。
- 必须提示：登录要求、当前积分规则、模糊扫描、手写、复杂表格、特殊字体、加密 PDF 的处理边界。
- 版式表述统一为“在技术允许时尽量保留”或同等含义，不使用绝对保证。

### 文档对比

- 可描述：上传原稿和修改稿；查看系统检测到的文字新增、删除和修改；结果并排展示。
- 必须提示：识别质量受原文和扫描质量影响；条款、数字、表格、签名、印章和格式变化需要对照原文件复核。
- 不得描述：法律意见、自动合规判断、完整 CLM、合同审批/续约工作流或未经验证的效率提升。

## 4. 变更流程

1. 产品能力、登录、积分、格式、文件大小、保留时间发生变化时，先更新本表和对应代码来源。
2. 再修改英语事实母版，并为每个语言建立“用户—文档—任务—限制—CTA”场景 brief。
3. 完成功能核对、语言审核、SEO 合同测试后再允许页面进入 sitemap。
4. 部署后检查生产 HTML、canonical、robots、结构化数据和实际功能，再进行 GSC 实时测试与请求收录。
