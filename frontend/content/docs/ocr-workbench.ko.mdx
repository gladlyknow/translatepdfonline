## 올바른 처리 방식 선택

OCR 작업 화면은 각 페이지가 이미지라서 텍스트를 선택하거나 복사할 수 없는 PDF에 적합합니다. 해외 논문 사본, 서명된 공급업체 문서, 기술 설명서, 종이 기록 스캔 등이 대표적인 예입니다. 이미 디지털 텍스트가 들어 있는 PDF라면 [일반 PDF 번역](/ko/translate)을 먼저 이용하세요.

## 시작 전 확인

- 파일 업로드와 처리에는 로그인이 필요합니다.
- 문서 언어와 지원되는 번역 언어를 선택합니다.
- 암호는 해제할 권한이 있을 때만 업로드 전에 제거하세요.
- 기울지 않고 대비가 선명하며 여백이 잘리지 않은 스캔을 사용하세요.

## OCR 번역 단계

1. [스캔 PDF OCR 번역기](/ko/ocrtranslator)를 열고 파일을 업로드합니다.
2. 원문과 번역 언어를 확인합니다. 필요한 페이지만 처리하도록 범위를 정할 수도 있습니다.
3. 작업을 시작합니다. OCR가 페이지 영역, 텍스트 블록, 읽기 순서, 표를 감지합니다.
4. 원본과 인식 결과를 비교해 이름, 숫자, 제목, 블록 순서를 수정합니다.
5. 검토한 내용을 번역하고 최종 페이지를 확인합니다.
6. PDF, Markdown 또는 HTML을 생성한 뒤 공유 전에 파일을 검토합니다.

문서나 작업이 활성화된 동안에는 현재 작업 내용을 바꾸지 않도록 재업로드가 비활성화됩니다. 일반 번역기가 스캔 PDF를 높은 확률로 감지하면 이 OCR 흐름으로 안내할 수 있습니다.

## 검토 체크리스트

- **이름과 식별 정보:** 인명, 회사명, 송장 번호, 제품 코드, 참조 번호.
- **숫자와 단위:** 날짜, 금액, 백분율, 치수, 소수점 표기.
- **페이지 구조:** 다단, 캡션, 각주, 머리글, 읽기 순서.
- **시각 요소:** 표, 도장, 서명, 손글씨, 페이지 가장자리 글자.

OCR와 번역은 검토를 돕지만 원본 대조를 대신하지 않습니다. 계약서, 논문, 의료·재무 문서는 관련 지식을 갖춘 사람이 최종 확인해야 합니다.

## 내보내기 형식

- **PDF:** 기술적으로 가능한 범위에서 검토한 페이지 구조를 따르는 문서를 만듭니다.
- **Markdown:** 편집 가능한 텍스트, 문서 작성, 후속 게시 작업에 적합합니다.
- **HTML:** 브라우저 검토 또는 웹 콘텐츠 재사용에 활용할 수 있습니다.

복잡한 표, 특수 글꼴, 저해상도 이미지, 손글씨는 어떤 형식에서도 수정이 필요할 수 있습니다.
