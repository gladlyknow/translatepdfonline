## Start with the document task

Use this documentation hub to choose a workflow before uploading a file. File processing requires sign-in. Translation, OCR, and conversion tasks use the credit amount shown in the product before processing starts.

- **Translate a text-based or scanned PDF:** open the [OCR PDF translator](/ocrtranslator), then follow the [upload workflow](/docs/upload) and [OCR workbench guide](/docs/ocr-workbench).
- **Extract selectable text from a PDF:** use the [PDF to Text guide](/docs/pdf-to-text).
- **Recognize text in a photo or scanned image:** use the [Image to Text guide](/docs/image-to-text).
- **Review differences between two document versions:** use the [Contract Comparison guide](/docs/contract-comparison).

## Supported languages and documents

The current language selector supports **English, Chinese, Spanish, French, Italian, Greek, Japanese, Korean, German, and Russian**. Select a supported source and target language before starting a translation.

Text-based PDFs can usually be read directly. Scanned or image-based PDFs need OCR first. The layout-aware pipeline attempts to place translated text back into the document structure where supported, but results vary with the source file, fonts, scan quality, tables, and page complexity.

Typical documents include research papers, technical manuals, supplier documents, reports, and other PDFs that need review before reuse.

## A typical PDF workflow

1. **Sign in and upload.** Choose the appropriate tool and add the source document.
2. **Set the task.** Select languages, a page range, or the two versions to compare, depending on the workflow.
3. **Recognize when needed.** Scanned PDFs and images go through OCR before their text can be translated or exported.
4. **Review the result.** Compare the source and output, and correct recognition or translation issues that matter to the document.
5. **Download or reopen.** Download the available output, or reopen a retained task from account history while it remains available.

## Check these limits before processing

- Password-protected or encrypted PDFs may need to be unlocked before upload.
- Blurry scans, handwriting, unusual fonts, complex tables, equations, stamps, and overlapping text may need manual correction.
- A page range can reduce processing time and credit use for long documents.
- Current credit use and any available introductory offer are shown in the product or account interface; this documentation does not promise a fixed price or free allowance.
- Output formats depend on the selected tool. Review important names, numbers, clauses, and table cells against the original file.

## Processing, privacy, and retention

Uploads, previews, and downloads are controlled from the browser, while OCR, translation, comparison, and document reconstruction run through backend services. Files move over HTTPS.

Uploaded and generated objects are normally scheduled for deletion after about seven days, subject to the published policy and legal requirements. Read the [Privacy Policy](/privacy-policy) and [Terms of Service](/terms-of-service) before processing confidential or regulated documents.
