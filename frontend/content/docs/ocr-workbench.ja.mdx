## 適切な処理方法を選ぶ

OCR 作業画面は、各ページが画像になっていて文字を選択・コピーできない PDF に向いています。海外論文のコピー、取引先から届いた署名済み資料、技術マニュアル、紙文書のスキャンなどが対象です。文字情報を含む通常の PDF は、まず[通常の PDF 翻訳](/ja/translate)を利用してください。

## 開始前の確認

- ファイルのアップロードと処理にはログインが必要です。
- 文書の言語と、対応している翻訳先言語を選びます。
- パスワードは、解除する権限がある場合に限って事前に外してください。
- 傾きが少なく、文字とのコントラストが高く、余白まで写っているスキャンを使います。

## OCR 翻訳の手順

1. [スキャン PDF の OCR 翻訳](/ja/ocrtranslator)を開き、ファイルをアップロードします。
2. 原文と翻訳先の言語を確認します。必要なページだけを処理対象にすることもできます。
3. タスクを開始します。OCR がページ領域、文字ブロック、読み順、表を検出します。
4. 原稿と認識結果を並べて、人名、数字、見出し、ブロック順を修正します。
5. 校正した内容を翻訳し、最終ページを確認します。
6. PDF、Markdown、HTML のいずれかを生成し、共有前にファイルを確認します。

文書またはタスクが開いている間は、作業中の内容を置き換えないよう再アップロードが無効になります。通常の翻訳機能がスキャン PDF と高い確度で判定した場合は、この OCR 手順へ案内されます。

## 校正チェックリスト

- **固有名詞と識別番号：** 人名、企業名、請求書番号、製品コード、参照番号。
- **数字と単位：** 日付、金額、割合、寸法、小数点の表記。
- **ページ構造：** 段組み、キャプション、脚注、ヘッダー、読み順。
- **画像要素：** 表、印影、署名、手書き、ページ端の文字。

OCR と翻訳は確認作業を補助する機能です。原本との照合に代わるものではありません。契約書、論文、医療・財務資料は、適切な知識を持つ人が最終確認してください。

## 出力形式

- **PDF：** 技術的に可能な範囲で、校正したページ構造に沿った文書を作成します。
- **Markdown：** 編集可能な文章、技術文書、後工程の公開作業に向いています。
- **HTML：** ブラウザでの確認や Web コンテンツへの再利用に使えます。

複雑な表、特殊なフォント、低解像度の画像、手書きは、どの形式でも修正が必要になることがあります。

## アカウント、保存、削除

処理にはアカウントが必要で、タスクはユーザーごとに分離されます。文書と関連オブジェクトは通常約 7 日後の削除対象となります。詳細と法令上の例外は[プライバシーポリシー](/ja/privacy-policy)をご確認ください。処理する権利のあるファイルだけをアップロードしてください。
