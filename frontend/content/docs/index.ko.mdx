## 문서에서 할 작업부터 선택하세요

이 문서 허브에서는 파일을 업로드하기 전에 적절한 흐름을 고를 수 있습니다. 파일 처리에는 로그인이 필요합니다. 번역, OCR 및 변환에 사용할 크레딧은 처리 시작 전에 제품 화면에 표시됩니다.

- **텍스트 PDF 또는 스캔 PDF 번역:** [OCR PDF 번역기](/ko/ocrtranslator)를 열고 [업로드 절차](/ko/docs/upload)와 [OCR 워크벤치 가이드](/ko/docs/ocr-workbench)를 확인하세요.
- **PDF에서 선택 가능한 텍스트 추출:** [PDF 텍스트 변환](/ko/docs/pdf-to-text)을 확인하세요.
- **사진이나 스캔 이미지의 문자 인식:** [이미지 텍스트 변환](/ko/docs/image-to-text)을 확인하세요.
- **두 문서 버전의 차이 검토:** [문서 비교 가이드](/ko/docs/contract-comparison)를 이용하세요.

## 지원 언어와 문서

현재 언어 선택기는 **영어, 중국어, 스페인어, 프랑스어, 이탈리아어, 그리스어, 일본어, 한국어, 독일어, 러시아어**를 지원합니다. 번역을 시작하기 전에 화면에서 제공하는 원문 언어와 번역 언어를 선택하세요.

텍스트 레이어가 있는 PDF는 일반적으로 바로 읽을 수 있습니다. 스캔 PDF나 이미지 기반 PDF는 먼저 OCR이 필요합니다. 레이아웃 인식 처리는 기술적으로 지원되는 범위에서 번역문을 문서 구조에 다시 배치하려고 하지만, 결과는 원본 파일, 글꼴, 스캔 품질, 표와 페이지 복잡도에 따라 달라집니다.

논문, 기술 매뉴얼, 공급업체 문서, 보고서처럼 다시 사용하기 전에 검토해야 하는 PDF가 일반적인 사례입니다.

## 일반적인 PDF 처리 흐름

1. **로그인하고 업로드합니다.** 작업에 맞는 도구를 선택하고 원본 문서를 추가합니다.
2. **작업을 설정합니다.** 흐름에 따라 언어, 페이지 범위 또는 비교할 두 버전을 선택합니다.
3. **필요할 때 OCR을 실행합니다.** 스캔과 이미지는 번역하거나 내보내기 전에 문자를 인식해야 합니다.
4. **결과를 검토합니다.** 원본과 출력을 비교하고 중요한 인식 또는 번역 오류를 수정합니다.
5. **다운로드하거나 다시 엽니다.** 사용 가능한 결과를 다운로드하거나 보관 기간 중인 작업을 계정 기록에서 다시 엽니다.

## 처리 전에 확인할 제한

- 암호화되었거나 비밀번호로 보호된 PDF는 업로드 전에 잠금을 해제해야 할 수 있습니다.
- 흐릿한 스캔, 손글씨, 특수 글꼴, 복잡한 표, 수식, 도장 및 겹친 텍스트는 수동 수정이 필요할 수 있습니다.
- 긴 문서는 페이지 범위를 지정하면 처리 시간과 크레딧 사용을 줄일 수 있습니다.
- 현재 크레딧 사용량과 이용 가능한 첫 사용 혜택은 제품 또는 계정 화면에 표시됩니다. 이 가이드는 고정 가격이나 무료 크레딧을 보장하지 않습니다.
- 출력 형식은 선택한 도구에 따라 다릅니다. 중요한 이름, 숫자, 조항과 표 셀은 원본과 대조하세요.

## 처리 방식, 개인정보 보호 및 보관

업로드, 미리보기와 다운로드는 브라우저 화면에서 제어합니다. OCR, 번역, 문서 비교와 문서 재구성은 백엔드 서비스에서 처리합니다. 파일은 HTTPS로 전송됩니다.
